HydroSense is a flood-awareness and response prototype with a citizen mobility experience, a municipal command dashboard, and a FastAPI backend.

## Project areas

- `user-frontend/` — citizen flood information, safe routes, reports, and alerts.
- `authority-frontend/` — municipal monitoring and incident response workspace.
- `backend/` — API, synthetic storm replay, gauges, road hydraulics, nowcasting, and cause explanations. See [backend/README.md](backend/README.md) for setup and its simulation scope.

The full logo and derived app icon/favicon files live in `assets/branding/`.
